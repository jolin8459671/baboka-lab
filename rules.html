How to play

玩法教學

從開局準備到一局怎麼結束，照順序整理。內容為玩家依規則書與實戰整理，若與官方正式規則有出入，一律以官方為準。

開局準備 回合流程 抽牌時機 技能與事件卡 局末與補牌 勝負條件 稀有度分級

開局準備

SETUP
  1. 雙方各自洗牌，牌組蓋著放在自己的牌組區。
  2. 猜拳等方式決定誰拿到發球權。
  3. 從牌組最上面抽6張當起始手牌。
  4. 起始手牌可以重抽 1 次——想換的牌放回牌組洗勻，再從最上面抽回等量的牌。
  5. 從牌組最上面拿 2 張蓋著放到 SET 區（這是你的「輸幾局才會輸掉整場」的緩衝額度）。
  6. 由拿到發球權的一方，從發球階段開始遊戲。

回合流程

SERVE → RECEIVE / BLOCK → TOSS → ATTACK
順序階段說明
1發球從手牌放 1 張角色卡到發球區，該角色的發球值＝這次的進攻點數（Offense Point）。
2選擇應對球來到你這邊時，二選一：接球 或 阻擋。對方的發球或阻擋回擊，只能選「接球」，不能選阻擋。
3a接球分支先經過抽牌，再放角色卡到接球區。接球值 ≥ 對方進攻點數＝接球成功，進入舉球階段。
3b阻擋分支從手牌放最多 3 名角色到阻擋區（先放 1 名主攔，再最多加 2 名副攔，同名角色不能一起登場）。阻擋值合計 ≥ 對方進攻點數＝阻擋成功，回擊給對方的進攻點數歸零；阻擋後副攔會被丟到棄牌區。
4舉球放 1 張角色卡到舉球區（不能跟接球區同名角色）。
5攻擊放 1 張角色卡到攻擊區（不能跟舉球區同名角色）。舉球值＋攻擊值＝這次扣球的進攻點數，換對方接招。
阻擋人數怎麼算：可以派 1～3 人一起阻擋，組合是「1 主攔」或「1 主攔＋1 副攔」或「1 主攔＋2 副攔」——主攔一定要先放，不能只派副攔湊人數。多人阻擋時，阻擋值是合計加總，例如主攔3 ＋ 副攔2 ＋ 副攔2 ＝ 這次阻擋值 7，只要對方進攻點數 ≤ 7 就阻擋成功。
宣告「落球」：角色卡放不出來、或接球／阻擋不成功時，要宣告「ロスト（落球）」，宣告的一方輸掉這一局（SET）。

抽牌時機

DRAW TIMING
  • 球來到你這邊、選擇 接球 時 → 先抽 1 張牌，再放角色卡接球。
  • 選擇 阻擋 時 → 不抽牌，直接進入阻擋階段。
  • 發球這個動作本身 → 不抽牌。
牌組抽完不會直接判輸，規則裡沒有「牌組空了就輸」這條——真正的敗北條件只有「無法繼續攻防」跟「SET 區沒牌可補」。

技能與事件卡怎麼疊

SKILLS & EVENTS STACKING
  • 每個階段都有自由步驟：只要符合該階段的時機圖示、付得起成本，同一階段可以連續發動任意張數的角色技能與事件卡。
  • 角色技能只能在卡片標示的登場區域觸發——例如某張卡寫「登場：阻擋區」，就只能放進阻擋區、也只有在阻擋區才能用他的技能，不能改放別區。
  • 發動成本通常是「支付 N 點資源（Guts／ガッツ）」——也就是從這張角色卡下方疊著的卡拿出 N 張丟棄，跟手牌是兩回事；少數卡片的成本明確寫「丟棄手牌」才會動到手牌。
  • 標示「每回合限用一次」的技能／事件卡，同一回合內不能重複發動第二次。

局末與補牌

END OF SET → INTERVAL
  1. 一局結束（有人宣告落球）後進入局間休息。
  2. 雙方都先把手牌補到 6 張（不夠的人從牌組抽牌補滿）。
  3. 輸掉這局的一方，再從自己的 SET 牌區 額外拿 1 張加入手牌——所以輸的一方最終手牌是 6+1＝7 張，贏的一方維持 6 張。
  4. 贏的一方獲得下一局的發球權，由拿到發球權的人從發球階段開始下一局。
關鍵敗北條件：如果輸掉一局時，自己的 SET 牌區已經沒有牌可以拿了，直接判定輸掉整場遊戲——這也是為什麼開局只給 2 張 SET 牌：等於「最多能輸 2 局的緩衝」，跟真實排球「輸 3 局就輸掉比賽」的設計互相呼應。

勝負條件

WIN CONDITION
  • 先取得 3 局（SET）勝利的一方，獲得整場遊戲的勝利。
  • 對手的 SET 牌區被拿光、又再輸一局時，直接判定敗北（不用真的打到 3 局全輸）。

稀有度分級

RARITY GUIDE ／ 卡片右下角小標記

每張卡右下角都有一個小標記，代表這張卡的稀有度或收錄分類。要留意的是， D／P 這兩個標記，講的是「這張卡從哪個產品收錄而來」，不是強弱高低； 真正代表「補充包裡由低到高」的稀有度階梯，是 N → R → S → 頂 → 秘 → 極 這條線。

標記意思
DDeck，起始套牌（スターターデッキ）收錄卡。跟稀有度高低無關，是獨立於下面那條階梯之外的分類——入門玩家人手一份的基本班底。
PPromo，促銷／宣傳卡。透過活動、加購、特典等方式額外發放，後面的數字代表第幾波促銷（P02、P03…）。
N補充包稀有度階梯最低一級，Normal。
RRare，一般稀有卡。
SSuper，比 R 高一級。
頂比 S 更高一級的稀有度。
秘附聲優燙金親筆簽名的卡。
極／極P目前最高等級，通常附序號、燙金簽名，部分為原作者親自繪製的限定版本。
NP／RP／SP／頂P對應等級的「パラレル版」，同一張卡的不同插畫／畫風版本。
D01、P02 這種「彈數編號」怎麼看：D 跟 P 各自有獨立的編號序列，互不影響—— D01 是「第 1 套起始套牌」，如果之後出新的起始套牌會是 D02； P02、P03 則是「第 2 波、第 3 波促銷活動」，會持續往上累加。 在卡牌資料庫的「系列」篩選裡看到的就是這組編號。
